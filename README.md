# Project Manager CLI

A Python based CLI (command-line interface) project management tool.

Add any number of tasks to a project, and any number of projects to a user.

## Features

* Tracks user, project and task data.
* Persistent data storage using JSON
* Interactive CLI with focus on readability and ease of use

## Requirements

* Python
* Rich
* pytest

## Running
In terminal run:
```bash
python main.py
```

## Testing

```bash
pytest
```
